# PrepLoom Deep Learning Notes Image Design System

Every Deep Learning note diagram must match the established PrepLoom course-note visual language.

## Required generation and validation

- Generate final note diagrams with the ImageGen skill.
- Save selected outputs as opaque PNG files in this directory.
- Inspect every output for technical accuracy, spelling, dimensions, and readability before use.

## Visual rules

- Canvas: opaque `1536 x 1024`, 3:2 landscape.
- Background: exact `#25282B`, including every edge and corner.
- Primary text: `#F2F0EB`.
- Primary linework: `#D8D6D1`.
- Secondary text and lines: `#A8AAAB`.
- Muted, nonessential details: `#777A7C`.
- Typography: clean sans serif similar to Geist Sans or Inter.
- Linework: consistent 2-4 px strokes, rounded corners, and technically correct arrows.
- Content: one technical idea per image, short labels, and generous spacing.
- Avoid: accent colours, pure black, pure white, gradients, glow, glass, 3D effects, texture, decoration, and watermarks.

Formulas and worked calculations belong in the live note layout whenever possible. Images should explain structure, direction, or relationships rather than act as screenshots of text.
