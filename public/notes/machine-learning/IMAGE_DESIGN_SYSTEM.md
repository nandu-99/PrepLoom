# PrepLoom Machine Learning Notes Image Design System

Every Machine Learning diagram follows the same visual language as the existing PrepLoom course notes.

## Required generation method

- Generate every final Machine Learning note image with the ImageGen skill.
- Save the selected final output as an opaque PNG inside this directory.
- Do not replace a final note image with a hand-authored SVG, canvas drawing, or CSS illustration.
- Inspect every generated output for technical accuracy, spelling, dimensions, and readability before using it.

- Canvas: opaque `1536 x 1024`, 3:2 landscape.
- Background: exact `#25282B`, including every outer edge and corner.
- Primary text: `#F2F0EB`.
- Primary linework: `#D8D6D1`.
- Secondary text and lines: `#A8AAAB`.
- Muted, nonessential details: `#777A7C`.
- Typography: clean sans serif similar to Geist Sans or Inter.
- Linework: consistent 2-4 px strokes, rounded corners, and clear arrow directions.
- Content: one technical idea per image, short labels, generous spacing, and no decorative elements.
- Avoid: accent colors, pure black, pure white, gradients, glow, glass, 3D effects, texture, and watermarks.

Every image must remain readable at normal article width and on mobile. Technical accuracy is more important than visual decoration.
