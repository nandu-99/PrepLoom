# Modern Computer Architecture Image Design System

Use this specification for every raster diagram in this subject.

- Canvas: 1536 × 1024 pixels, opaque PNG, 3:2 landscape.
- Background: solid charcoal `#25282B`.
- Main text and nodes: warm off-white `#F2F0EB`.
- Linework: light gray `#D8D6D1`.
- Secondary text: gray `#A8AAAB`.
- Muted structure: gray `#777A7C`.
- Style: flat, clean, technical, editorial, and easy to scan.
- Layout: one main idea per image with generous spacing and short labels.
- Avoid: color accents, gradients, glow, glass, 3D effects, photographic elements, texture, and unnecessary decoration.
- Accuracy: all bit patterns, formulas, signal names, arrows, and mappings must be checked before use.
- Accessibility: every image needs descriptive alt text and a short caption in the course content.
