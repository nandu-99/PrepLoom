# PrepLoom DBMS Notes Image Design System

Every DBMS note diagram must use the same visual language as the existing PrepLoom Operating Systems diagrams.

## Fixed style

- Canvas: opaque `1536 × 1024`, 3:2 landscape.
- Background and outer corners: exact `#25282B`.
- Primary text: `#F2F0EB`.
- Primary lines: `#D8D6D1`.
- Secondary text and lines: `#A8AAAB`.
- Muted, nonessential details: `#777A7C`.
- Typography: clean sans serif similar to Geist Sans or Inter.
- Linework: consistent 2–4 px outlines with restrained rounded corners.

## Content rules

- Explain one main idea per image.
- Use short, simple labels that match the notes exactly.
- Keep arrows and database relationships technically correct.
- Make every label readable at article width and on mobile.
- Prefer flows, layers, tables, trees, and balanced comparisons.
- Do not add facts that the topic does not explain.

## Avoid

- Accent colors, pure black, and pure white.
- Visible gradients, glow, glass, 3D effects, texture, and decoration.
- Long paragraphs, unnecessary icons, people, scenes, and watermarks.

## Prompt base

Use case: scientific-educational. Asset type: PrepLoom DBMS course-note diagram. Style: premium monochrome technical infographic with clean vector-like outline linework. Keep the exact palette, 3:2 format, generous margins, short labels, correct relationships, and one clear idea.

## Validation

- Check spelling and every arrow direction.
- Check that labels match the written topic.
- Check the exact palette and opaque corners.
- Keep the image only when it teaches the idea more clearly than text alone.
